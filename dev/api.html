IonosphereElectrodynamics Module
julia
IonosphereElectrodynamics

Standalone, zero-allocation 2D spherical magnetosphere–ionosphere (M–I) coupling solver. Solves the height-integrated ionospheric potential equation     on both hemispheres in dipole SMG coordinates and maps potentials, electric fields, and   convection velocities along dipole field lines.

Dipole Frame & Field-Line Mapping ​

IonosphereElectrodynamics.DipoleFrame Type
julia
DipoleFrame{FT <: AbstractFloat}

Immutable, isbits orthonormal Solar Magnetic (SMG) coordinate frame built from a 3D planetary dipole moment vector.

  • center: Body / dipole center in simulation coordinates.

  • rot: Orthonormal rotation matrix whose rows (e1, e2, e3) map simulation vectors to SMG coordinates (x_smg = rot * (x_sim - center)), with e3[3] >= 0 pointing toward geographic/simulation North.

  • dipole_moment, M0: 3D dipole moment vector and magnitude norm(dipole_moment).

  • dipole_sign: -1 for Earth-like polarity (m ⋅ e3 < 0), +1 for reversed polarity.

  • r_iono: Ionospheric shell radius in simulation length units.

source
IonosphereElectrodynamics.build_dipole_frame Function
julia
build_dipole_frame(
    dipole_moment;
    center = (0.0, 0.0, 0.0),
    r_iono = 1.0,
    FT = Float64,
) -> DipoleFrame{FT}

Construct a DipoleFrame from dipole_moment, matching FLEKS's SMG convention: e3 always points toward northern simulation hemisphere (e3[3] >= 0), dipole_sign records the polarity along e3 (-1 Earth-like, +1 reversed), and e1 is the projection of simulation +x (falling back to +y when |e3[1]| > 0.99) orthogonal to e3.
